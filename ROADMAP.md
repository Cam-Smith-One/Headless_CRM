# Roadmap

This is the working roadmap for making Headless CRM the best open-source CRM for humans and agents to run together.

## Now

- Finish invite and team-management end-to-end coverage.
- Add a stronger Postgres operator guide with backup and restore procedures.
- Improve error states and operator feedback in the dashboard.
- Expand example integrations for common MCP clients and automation runners.

## Next

- Granular permissions beyond the current core role set.
- Better import/export workflows for contacts, companies, and deals.
- External attachment storage for production workloads.
- A richer audit and security activity UI for admins and auditors.
- More realistic demo data and walkthrough assets for the repo.

## Later

- Real-time updates for the dashboard.
- More packaged integrations and webhook recipes.
- A cleaner plugin/extension story for custom entities and automations.
- Deployment blueprints for common self-host targets beyond local and Vercel.

## Non-goals for now

- Turning the OSS repo into a hosted SaaS clone.
- Hiding the operational tradeoffs between SQLite and Postgres.
- Supporting every CRM customization model before the core paths feel excellent.
