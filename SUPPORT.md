# Support

Headless CRM is maintained as an open-source project with best-effort support.

## Where to go

- **Bug reports:** open a GitHub issue with reproduction steps.
- **Feature requests:** open a GitHub issue and explain the use case.
- **Security reports:** follow [SECURITY.md](./SECURITY.md) and report privately.
- **Setup or operational questions:** include your deployment mode, database mode, logs, and the command you ran.

## What to include

Please include:

- commit SHA or release version
- Node.js version
- whether you are using SQLite or Postgres
- whether the issue happens in `npm run dev` or `npm run selfhost:sqlite`
- relevant logs or screenshots

## Support expectations

- Setup help and verified bugs are the highest priority.
- Security issues should be reported privately.
- Feature requests are evaluated based on usefulness to both humans and agent-driven workflows.

If you need a fully managed experience, the hosted version is linked from the README.
